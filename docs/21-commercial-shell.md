# toboo 三页产品界面

2026-11-09：将本聊天已选的陪伴、设备、设置概念图还原为 Avalonia 原生桌面界面。保留 .NET 8、Avalonia 11、FluentTheme 和现有青绿色主题，不引入 Web 前端、Tailwind 或新的运行依赖。

## 页面与功能

| 入口 | 当前行为 |
| --- | --- |
| 陪伴 | 欢迎空状态、机器人插图、真实视觉预览与表情摘要；文字、语音输入在服务未接入时明确禁用，没有虚构聊天回复 |
| 设备 | 摄像头枚举/选择/刷新、启动与停止人脸表情预览、表情开关；云台回中心/实物跟随复用原控制门槛；校准入口打开原有工具 |
| 设置 | 首页感知栏开关、本地表情开关可用，运行时表情配置锁定；对话/声音显示待接入；隐私页说明本地分析和现有实验日志行为 |
| 高级调试 | 完整保留原采集、控制参数、舵机校准、对准、表情分数、录像首框、曲线、标记和CSV导出 |
| 传感器遥测 | 沿用原有独立窗口；UNO遥测不因UI重组而假定已连接 |

设置中的“首页视觉感知”只决定是否展示该区域，不停止采集；表情开关决定下一次视觉会话是否运行分类。两个开关当前用于本次应用会话，不显示“已自动保存”。DeepSeek密钥、聊天、ASR、TTS、蓝牙音响和LCD发送未在本次实现，也没有可点击的虚构测试/连接操作。

设备未开启时不显示已连接；没有串口状态与供电确认时，回中心和跟随继续禁用。LCD卡片标明“颜文字效果示意”。图片、录像和合成画面仍标明来源，不包装成实时相机或硬件实测。

## 结构与会话所有权

- `MainWindow` 为产品壳，`CompanionShellViewModel` 负责导航和状态投影。`MainViewModel` 继续拥有原采集、表情分析与控制会话。
- 三个原生 `UserControl` 位于 `Views/`。原窗口迁为 `AdvancedWindow`，原处理器、图像坐标和绑定保留。
- 产品壳打开高级调试时传入同一 `MainViewModel`；导航和关闭高级窗口不会停止或释放共享会话，不创建第二个摄像头采集器。关闭主窗口仍停止会话并释放资源；舵机忙碌时沿用原关闭保护。
- 原有工作台测试迁到 `AdvancedWindow`，断言与硬件控制测试继续保留。新增产品壳测试覆盖导航期间帧数持续、关闭共享窗口后采集继续、主窗口关闭后停止，以及空状态/运动按钮门槛。
- `-Expression` 直接进入设备页；`-ServoCalibration` 进入产品壳并打开原校准工具。启动不会自动采集或转动云台。

## 设计约束与验收

已按 Refactoring UI 的层级、布局、排版、颜色、图像顺序审查；适配现有桌面技术栈和用户选定的概念图，未套用Web组件或默认配色。

| 发现 | 调整与规则 |
| --- | --- |
| 原首页并列展示采集、控制和遥测，普通操作被调试信息竞争 | 三页导航；实验工具收进高级窗口。§2.1、§2.4 |
| 单一左栏承载所有表单 | 独立设备总览与设置分组，组间留白大于组内。§3.4.1、§3.6 |
| 示例连接状态与未来对话易被误解为已实现 | 使用真实状态、禁用未接入功能并写明原因；相机空状态提供明确入口。§5.7、§8.4 |
| 首次渲染发现状态行重叠、插图比例偏小 | 修正网格列与插图显示比例。§2.1、§7.3 |
| 常规禁用控件灰底视觉过重 | 产品壳采用低强调背景，保留禁用语义和说明；不改硬件门槛。§2.4、§2.8 |
