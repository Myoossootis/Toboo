# STM32 固件阶段

具体开发板型号和通信接口待确认。当前没有可声称支持某块 STM32 的固件、HAL 配置或二进制。

根据用户 2026-10-29 的反馈，舵机控制板 USB 仅支持 Host，不能作为 PC 的 USB Device 控制入口。主路线仍为 PC → STM32 → 控制板。先前商品图已明确 UART／I²C 控制能力并给出 3.3V STM32 的 I²C 接线示例，详见 docs/03-hardware-checklist.md；后续先读取该控制板专用命令协议，不重复询问已写明的控制能力。现有 STM32 的 PC 连接方式单独核对。

后续按以下顺序实现：

1. PC 通信收发与状态回报，不连接舵机。
2. 参数合法性、方向、限位与独立超时保持测试。
3. 根据实际亚博驱动板对应版本的 UART／I²C 协议选择一种接口，逐轴小幅运动。
4. 单轴闭环，再加入俯仰。

PC 的项目协议和驱动板的厂商协议不是同一套。拟定协议见 protocol-v0.md；实现前对两端统一版本。
