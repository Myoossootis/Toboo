# toboo v0.3.0

本版增加独立视觉标定页、本机相对深度和彩色点云、Uno LCD 与超声波共板测距，以及本地语音跟随命令。Windows x64 便携包附带 .NET、OpenCV、MiDaS、Whisper、VAD 和串口工具运行环境。

## 新功能

- 左侧「视觉标定」直接选择 USB 摄像头、导入照片、查看相对深度和交互点云，拖拽旋转、滚轮缩放。
- 棋盘格相机标定及 DICT_4X4_50 / ID 7 定位，二维轨迹与超声波回波观测，失去定位时暂停入图。
- 5V 四针超声波与 LCD1602 共用 Uno。TRIG D7、ECHO D8，LCD SDA A4、SCL A5，共用 5V/GND 和 USB 串口。
- 低于设定距离显示近障提示，初始阈值 350 mm。
- 陪伴页按住说「打开摄像机跟随」，松开后执行本地命令。Harness 离线可用，设备供电、标定和方向需预先确认。
- S1 回位支持保存在本机的独立 PanCenter，中心须位于工作边界内。原有配置省略此项时仍用边界中点。

## 下载

- `toboo-0.3.0-win-x64-portable.zip`，完整解压后双击 `toboo.exe`。
- `toboo-0.3.0-uno-lcd-distance.hex`，LCD 与超声波共板固件。
- `toboo-0.3.0-uno-lcd.hex`，LCD 单独固件。
- `toboo-0.3.0-esp32s3-n16r8-ics43432-positional.bin`，ESP32-S3 N16R8 的采音与角度定位型云台合并固件，启动为 DISARMED。使用前确认定位型舵机、接线和工作边界。
- `toboo-0.3.0-esp32s3-n16r8-ics43432-motion-locked.bin`，采音与全执行器输出锁定固件，适合仅采音或尚待核对的执行器配置。
- `toboo-0.3.0-firmware-source.zip`，对应固件源码、构建脚本和 hd44780 依赖源码与许可。
- `SHA256SUMS.txt`，附件完整性校验值。

ESP32 BIN 是 16 MiB 合并镜像，适用写入偏移 0x0，需要匹配 N16R8 板卡。上传方法见 [麦克风说明](../microphone.md)，Uno 方法见 [LCD 说明](../lcd.md)及[共板接线](../aruco-sonar-map.md)。已有同功能固件的设备可以直接换电脑连接。

## 换电脑

另一台电脑使用 Windows 10/11 x64，完整解压到可写目录。直接连接 USB 摄像头即可预览，本机拍照深度估计可离线使用。点云来自单帧相对深度，尺度为显示用途，跨帧二维地图需要完成相机标定和固定标记定位。

新电脑会重新枚举 COM 口，分别选择 ESP32 和 Uno。相同且未改变安装的装置可由用户自行复制原电脑 `%LOCALAPPDATA%\PanTiltTracker\servo.json` 和 `face-aim.local.json` 到新电脑同目录，再核对摄像头、方向和工作范围。首次供电确认与回位仍在设备页完成。更换摄像头或采集尺寸后重新做相机标定。

中文电脑麦克风识别和朗读使用 Windows 中文语音组件。ICS43432 识别使用包内模型，要求 CPU 支持 AVX2、FMA、F16C。聊天在另一台电脑安装并配置 DeepSeek Harness，再执行包内桥安装脚本。具体步骤见 [便携版说明](../portable.md)。

## 验证与适用范围

发布检查包括完整 .NET 回归、原生界面、固件主机逻辑、固件构建、独立解压启动、模型哈希、原生深度推理、语音和内置串口运行环境。便携测试屏蔽系统 .NET/Python 搜索路径。

本机实测已确认实时相对深度与点云更新、超声波固定目标重复读数、LCD 表情与近障提示。ArUco 实物标定与地图尚待测试。另一台具体笔记本上的性能、设备驱动和运动表现需在当地验收。
