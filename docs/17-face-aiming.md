# 人脸对准：视觉稳定与角度请求框架

2026-11-07。无人机路线暂时搁置，当前目标是人脸检测并让云台相机对准。这里的“人脸”是检测目标，不进行姓名、身份或活体识别。本文负责视觉闭环上层；另一条硬件工作线负责 ESP32、串口、两轴 S 曲线插补及输出许可。

## 当前代码与职责

原实现 YuNet 每帧选择最大框，`PanTiltController` 将归一化像素误差比例转换为角速度，再积分为请求角度；只有速度和范围限制，没有人脸关联、时域滤波、角度投影、滞回或加速度限制。多人框大小交替时可能跳换，直接将此输出接入舵机会放大检测抖动。

新增 Core 纯数学模块（无 OpenCV、UI、串口依赖）：

- `FaceTargetLock`：使用当前帧框进行空间关联，首选最大框作为候选，连续 3 帧确认后锁定；随后优先关联原目标，不追逐远处更大的人脸。
- `CameraAngleModel`：将像素坐标变为视线角偏差，支持明确填写的水平/垂直 FOV 近似，或已标定的 fx、fy、cx、cy。
- `FaceAimController`：锁定、时间滤波、死区滞回、角速度/加速度约束、请求限位、缺失/旧帧保持。
- `FaceAimResult`：向上层返回原始观测、滤波位置、视线偏差、双轴请求与速度、锁定代次、就绪条件。没有硬件写入。

桌面的人脸录像/摄像头模式已接入；图片继续是单帧检测，不要求连续确认。ArUco、旧通用控制器、无人机实验和台架扫动未替换。所有检测框仍显示，绿色为锁定目标，黄十字为滤波中心。确认期间有框但不输出已确认目标；检出率此时反映已确认目标覆盖率。

## 处理顺序

`当前图像 → YuNet → 空间关联/连续确认 → 中心时间滤波 → 视线角偏差 → 滞回死区 → 比例角速度 → 限速/限加速度 → 角度请求限位 → 上层结果`

**空间锁定。** 面积比限定 0.25–4，IoU 至少 0.15 或中心距离不超过旧框对角线的一半；多个匹配时选最近者。锁定缺席的当前帧立即报告空观测并保持，不复用旧框；保留关联参考最多 0.4 秒，期间拒绝跳到远处第二个人。到期后新候选重新确认。锁定代次不代表物理身份；人脸交叉、遮挡或快速运动仍可能丢失/关联错误。

**时间滤波。** 使用 `alpha = 1 - exp(-dt / tau)` 的一阶低通，默认 tau=0.10 秒；dt 来自单调采集时间，适应帧率变化。只处理当前确认的检测，不预测未来位置，不在漏检时生成目标。低通会带来响应延迟，不能无限调大；tau=0.10 的理想阶跃约 0.23 秒达到 90%，不含确认、相机及舵机延迟。

**角度换算。** 对应相机坐标向右/向下为正：

```
nx = (u - cx) / fx
ny = (v - cy) / fy
水平视线偏差 = atan(nx)
垂直视线偏差 = atan2(ny, sqrt(1 + nx*nx))
fx = width / (2*tan(horizontalFov/2))  // 仅 FOV 近似模式
```

公式输出转换为度。目标是光轴方向 cx、cy；主点不居中时与图像中心十字不完全相同。对应 [OpenCV 针孔模型](https://docs.opencv.org/4.11.0/d9/d0c/group__calib3d.html)。这些是相机视线偏差，不能直接作为舵机绝对角。方向经装配确认后，按当前请求参考逐步修正；双轴耦合、安装偏心、机械回差和执行延迟仍需实物测量。

同视野、同宽高比的缩放同步缩放内参；宽高比差异超过 1% 阻止角度请求。仅凭宽高比无法检测同形状裁剪或驱动改变视场。当前模块不自动去畸变；真实镜头有畸变时必须先对点去畸变，并提供对应内参，或明确将结果作为近似。不能将对角 FOV 当作水平 FOV。没有从“200W”像素数猜测镜头参数。

**抗抖动与平滑。** 每轴进入中心死区为 1°，离开需超过 1.8°，避免阈值附近反复起停。离开后 `desiredVelocity = direction * gain * (error - sign(error)*1°)`；默认 gain=2/s，每轴速度上限 15°/s、加速度上限 60°/s²。使用梯形积分得到连续请求角。没有积分误差项、微分项或运动预测；先避免积分饱和和微分放大检测噪声。此处不承诺 jerk 上限。

**异常保持。** 画面到达后超过 0.2 秒、重复帧号/采集时刻、目标缺失时立即保持请求角、清空滤波/速度，不沿旧速度继续运动。缺失前的最后角不补算。采集间隔或连续有效控制间隔超过 0.15 秒时重新确认；第一次重新锁定只建立时基，不积分旧时间。缺失保持和限位停止优先于平滑减速，所以这些停止不受正常运行加速度约束。

## 参数与预览

`config/face-aim.json` 为单独的初步参数，打包到桌面程序旁；可用 `%LOCALAPPDATA%/PanTiltTracker/face-aim.local.json` 覆盖，运行前读取。实际测量文件不要提交 Git。原 `tracker.json`、界面常规增益/速度/反向滑块仍用于旧通用控制链，不覆盖人脸参数；界面已有提示。

默认 camera=null、directionsConfirmed=false，不假设相机视场和安装方向。请求范围取现有台架工作约束 S1 30–175°、S2 35–65°；是初步软件限位，不代表新增实物验证。硬件线可能调整这些范围，接入前必须取主机/固件/实测允许范围的交集。初始预览内部占位取边界几何中心，既不发送，也不当作轴位：没有请求参考时，UI/CSV 的舵机角度为空。

可以通过 `SessionOptions.FaceAim` 显式注入设置。FOV 近似仅用于计算试验，例如：

```csharp
// 以下 60°/45° 是示例假设，绝非亚博摄像头实测值。
var settings = new FaceAimSettings {
    Camera = CameraAngleModel.FromFieldOfView(640, 480, 60, 45),
    DirectionsConfirmed = false
};
var preview = new FaceAimController(settings); // 没有参考，不会许可角度请求
```

默认桌面不提供/恢复历史请求参考。因此即使配置了相机和方向，也只计算视线误差，不驱动云台。将来上层在显式启动控制时传入 `AimReference`（两轴末次已接受请求，不是实测轴位）；`SessionOptions.FaceAimReference` 已保留会话内入口。换会话、断动力、改装配后不得静默复用参考。

CSV 保留原列顺序，追加滤波中心、视线角偏差、请求速度、锁定代次、`aim_readiness`、`aim_request_permitted`、`aim_has_reference`。raw u/v 为当前选定检测中心，error_x/y 为滤波后的图像归一化偏差。没有当前目标时坐标/角偏差为空；无参考时请求角列为空。run.json 记录设置、参考及 preview_only，hardwareOutput 始终 disabled。

## 给舵机侧的集成约定

1. 上层仅消费当前会话、最新有效帧的 `FaceAimResult`。`RequestPermitted=true` 只是计算条件满足，不等于硬件已经启用；仍需独立 arm、会话/序号、超时、范围校验与停止逻辑。
2. 单一调度线程独占串口，手动扫动/回位与视觉跟随互斥；使用覆盖式最新目标，不排队追赶历史框或积压角度。无新帧时不要反复调用旧检测来产生移动。
3. 缺失/旧帧/停机要取消 MCU 尚未完成的运动目标，不能只停止更新目标又用 KEEP 维持旧行程；仅停发时也仍有固件超时窗口。输出关闭不等于动力断开。
4. 台架“固定终点 S 曲线”与视觉“持续更新目标”是不同工作方式。每帧重新启动一条从零速度开始的长 S 曲线会拖慢甚至阻碍跟随，不直接调用一次性 ServoTool 动作循环代替流式传输。需要硬件侧明确提供可重定向的跟随接口，保持速度连续并保留失联保护，再接本模块。
5. 此模块保留浮点请求，整数度量化由传输/固件侧负责去重；不要每帧 round 后反复发相同目标。现有 `$Axxx#/$Bxxx#` 的 1°量化、舵机机械死区和供电抖动限制最终效果。没有编码器无法声称实测轴角精度或消除机械振动。

本次没有修改固件、串口工具、ServoViewModel 或扫动流程，没有启用自动跟随输出，也没有发布 Release。

## 验证与下一步

新增纯数学测试覆盖角度/分辨率/符号、确认、第二人抢框、丢失重捕获、无标定/无方向/无参考、错宽高比、中心抖动、死区滞回、速度/加速度、反向与限位、旧帧/重复/长间隔和理想闭环。

抖动样例为中心 ±8px 交替扰动，过滤后稳态均方偏差小于原始的 10%，且该样例不产生角度移动。理想瞬时执行器样例从水平 15°偏差收敛到 1.8°以内；不包含曝光/USB/串口延迟、量化、回差或惯性，不能作为实物精度报告。

桌面集成测试用合成空白录像核验配置和空目标日志；可设 `UAVTRACK_FACE_TEST_IMAGE` 为公开人脸样例，生成 5 帧人脸＋2 帧空白的小录像，实际运行 YuNet、确认、角度计算、预览与日志，核验漏检即清空。没有保存用户相机原图。原生模型/录像集成与合成数学测试都不代表云台验收。

接下来：固定摄像头模式，标定或测量 FOV；人工小幅确认两轴修正方向；由硬件线落实流式目标更新/取消语义后，先低速单轴再双轴，测中心误差 RMS、最大超调、稳定时间、丢脸停止延迟和一分钟静止抖动。确认精度目标应结合整数度协议再设定，不预先承诺亚度级机械精度。
