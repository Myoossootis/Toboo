1. `16路舵机驱动/1.16路舵机驱动资料/16路舵机驱动资料.pdf`：动力输入 5–8.4V，舵机电源由输入决定；主电源是蓝色螺丝端子。
2. `16路舵机驱动/0.16路舵机驱动板电池连接/1、电池连接说明.pdf`：7.4V 电池供电时舵机端为 6–8.4V，禁止连接 5V 舵机。
3. `16路舵机驱动/4.STM32驱动资料/STM32F103C8T6&GD32/接线注意事项（必看）.txt`：通信口 VCC 是 3.3V，禁止接 5V；已接主动力电源时，通信只接信号和 GND，VCC 可以不接。
4. 通用 Pico 舵机教程参数表列出 SG90 的 4.8–6V、堵转电流 750mA±10%。这是该例程的舵机参数，不当作用户实物金属齿舵机的型号或实测电流。

## 采购结论

按当前低压双小舵机桌面实验，建议买 **固定输出 DC 5V、持续额定 3A 的封闭式稳压适配器**，直接接驱动板动力端子。不采用旧候选“12V、1A 加多路 LM2596”，本阶段也无需电池与充电器。

配套买 **DC 5.5×2.1mm 母头转红黑两芯裸线**，与适配器的同规格中心正公头配套；建议 18–20AWG，接线尽量短。若适配器直接提供合适的红黑输出线，则省去转接线。5.5×2.1mm 是为此次购买选择的适配器与线材配对规格，不是宣称驱动板自带该插座。

优先正规供应商、额定持续电流清晰、有适用安规认证的电源。5V、3A 是留有余量的选型，不是两轴启动/堵转实测验收，也不提高板上过流保护门限。若选更大电流额定值，电压仍保持 5V。供电线不要用细杜邦线代替。

参考厂商规格例：明纬 GST18A05-P1J 为 5V、3A，P1J 是 5.5×2.1mm 中心正插头；该桌面型号还需要配交流输入线。它仅作为完整规格可核验的例子，不限定必须购买此型号或声明已询得价格。

规格来源：https://www.meanwell.com/Upload/PDF/GST18A/GST18A-SPEC.PDF

接法：适配器 → 配套母头红黑线 → 蓝色动力端子（按板上正负标识）。摄像头继续 USB 接 PC；STM32 维持其自己的 USB/规定电源，通信连接与控制板共地，初次联调不连接控制板通信口 VCC。

到货先用万用表确认输出约 5V、极性正确，再分别测试单轴和双轴运动，检查复位、掉压和发热。若没有万用表，借用或补充基础款即可，不需要为此购买示波器或台式电源。

## 教程存在的版本差异

- 云台旧树莓派 `180度舵机的使用说明.pdf` 写直接接 7.4V，不能覆盖电池说明中针对低压舵机的明确限制；按实际舵机额定值选择。
- 控制板主说明为 7 位 I²C 地址 0x2D，STM32 软件 I²C 例程发送 0x5A（含写位）；树莓派旧说明中的 0x52/0x29 不作为本板确定地址。
- UART：9600 波特，编号 A–P，三位十进制角度，例 `$A010#`。STM32 UART 示例为 PA2/TX → 板 RX、PA3/RX ← 板 TX，I²C 为 PB6/SCL、PB7/SDA。用户实际板型还需匹配。
- 个别云台教程含 270° 舵机，控制板基础协议却只定义 0–180；实物角度和机械范围需要到货逐轴测定，不能直接运行全范围摆动示例。
- ROS 目标跟踪教程实际启动 CamShift，并把 CSRT/MOSSE 错分为深度学习；沿用当前项目的实际算法定义，不照抄该分类。
