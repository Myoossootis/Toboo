# 开始使用 toboo

## Windows 便携版

1. 在 [Releases](https://github.com/Myoossootis/Toboo/releases/latest) 下载完整的 `win-x64-portable.zip`。
2. 将整个文件夹解压到可写目录，保留 DLL、`models`、配置文件和 `licenses`。
3. 双击文件夹中的 **`toboo.exe`**。不要直接在压缩包内运行，也不要只复制 exe。
4. 左侧提供陪伴、设备、视觉标定和设置。云台连接与跟随在设备页完成，点云和棋盘格标定在视觉标定页完成。

便携版自带 .NET 运行时与原生图像依赖，只面向 Windows x64。本版本是原型版本，首次使用无需连接舵机或传感器。

## 从源码启动

安装 .NET 8 SDK，在仓库根目录双击 `start-toboo.cmd`。脚本自动构建桌面项目并打开 toboo；失败时保留控制台错误。也可以运行：

```powershell
./scripts/start-toboo.ps1
# 可选：启动表情、传感器或设备准备向导
./scripts/start-toboo.ps1 -Expression
./scripts/start-toboo.ps1 -Sensors
./scripts/start-toboo.ps1 -ServoCalibration
```

正常启动不会自动打开摄像头、串口或启动运动。源码构建输出在 `artifacts/toboo/`，无需在 `src` 中查找 exe。

## 配置对话

聊天需要单独配置 DeepSeek Harness 和模型服务。未连接时，toboo 的其他本地功能仍可使用。安装步骤见 [Harness 接入](harness.md)。文本框、流式回复、停止、新建与历史会话均在 toboo 内操作。

## 语音对话

预置本地命令为「打开摄像机跟随」。在陪伴页按住语音按钮，说完整短句后松开，识别完成即请求开启人脸实物跟随。电脑麦克风和 ICS43432 均支持，本地命令可在 Harness 离线时使用。命令使用设备页已经选择的 ESP32、供电确认、标定边界和两轴方向，条件不足时会显示缺少的准备项。视觉标定正在采集时，会先释放相机。当前语音操作使用按住说话输入。

连接 Harness 后，在陪伴页按住「按住说话」，说完松开即发送。也可以把焦点移到按钮上，按住空格或 Enter 说话。按 Esc 或「停止语音」可取消当前识别。

新回复会通过系统中文声音朗读。「朗读回复」可随时关闭，偏好保存在本机。按住麦克风可打断朗读，开始下一句。表情随倾听、思考和实际播放切换。

电脑麦克风使用 Windows 中文识别，ICS43432 使用本地 Whisper，朗读使用 Windows 中文声音。识别、朗读均在本机运行，原始音频保留在内存中。松开后只有识别文字经 Harness 发给模型。单次按住最长 30 秒。

使用 Windows 默认麦克风和音频输出。蓝牙音响连接电脑后，可在 Windows 声音设置中将其选为默认输出。「设备 → 语音 → 检查本机语音」显示语言组件状态；若缺少组件，在 Windows 的语言设置中为简体中文添加语音识别与文字转语音组件，再重新检查。麦克风无法使用时，检查默认输入设备、桌面应用麦克风权限和其他应用占用情况。

也可在设备页选择 ICS43432 与 ESP32-S3 的串口，再按住语音按钮使用模块采音。便携包附带识别模型，源码使用前执行 `./scripts/prepare-speech-model.ps1`。模块转写不需要 Windows 中文听写语言包。接线及合并固件见 [麦克风说明](microphone.md)。

可显式执行以下本地自检，将生成的中文语音送回本地识别引擎。结果写入诊断目录。

```powershell
./toboo.exe --speech-self-test
```

## 摄像头和表情

在设备页面选择摄像头并启动预览。高级工作台还支持图片和录像。只查看图像和表情不需要连接或启用舵机。

表情为七类可见线索，光照、模糊、侧脸、遮挡和不确定分数都会导致 Unknown。Unknown 是保守拒判，不是第八种情绪。详见 [表情算法](expressions.md)。

## 云台跟随

日常操作在设备页完成：选择 ESP32 串口 → 连接并读状态 → 确认供电 → 回中心 / 开始跟随。LCD 与传感器也使用下拉串口列表，新插入设备后点击刷新，不自动猜测板卡。

首次使用或硬件变更时，打开“快速准备”，依次确认连接与供电、工作边界、相机与修正方向。每次只显示一步；详细的角度边界、内参和速度位于默认折叠的“高级设置”。已保存且仍适用的校准直接复用，无需每次重做。

从实时摄像头预览可以直接切换到跟随，应用先停止预览并释放相机，再重新检查就绪条件，随后启动跟随。停止未完成、校准失效或串口未就绪时显示准备项。点击启动按钮或明确的本地语音命令可以请求跟随。

## LCD 表情屏

使用已烧录专用固件的 UNO 和 5V 四针 I²C LCD1602。在设备页选择对应 UNO 串口并连接，新插入设备后可点击“刷新”。屏幕显示对话动作与七类实时表情线索；离开画面或停止识别后恢复待机。便携版内置串口支持，接线及固件步骤见 [LCD 使用说明](lcd.md)。

## 本地文件与故障排查

- 便携版诊断信息写入程序目录的 `diagnostics/`；源码启动生成输出在忽略的 `artifacts/`。
- 为兼容已有安装，摄像头与舵机设置继续保存在 `%LOCALAPPDATA%\PanTiltTracker\`；升级不更改已保存的标定和运动范围。
- 聊天桥的令牌、历史和运行状态在 `%USERPROFILE%\.toboo-harness\`，不在发布包中。不要分享整个目录或连接文件。
- 启动失败：先确认完整解压、系统为 x64、目录可写，再查看 `diagnostics/startup-error.json`。
- 摄像头无画面：检查系统相机权限、设备选择及是否被其他程序占用。
- 串口运行环境不完整：重新完整解压程序，保留 `runtime/python/` 和 `firmware/tools/`；便携版不需要安装全局 Python 或查找源码目录。
- 对话未连接：核对 Harness 是否正在运行并加载了桥插件；从托盘退出后重启可重新加载插件。

版本升级请完整解压到新文件夹，关闭旧版后运行新目录的 `toboo.exe`。本版不提供跨版本 DLL 覆盖更新。
