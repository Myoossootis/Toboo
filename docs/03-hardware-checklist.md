## 已收到的接口信息

2026-10-29，用户反馈：舵机控制板的 USB 端口用于连接外设，工作于 Host 模式，不能作为 Device。此项为用户提供的信息，尚未进行实物验证。

- 不将该 USB 端口规划为 PC 的 USB 虚拟串口或原生 USB 控制入口。
- 继续按 PC → 现有 STM32 → 舵机控制板 UART／I²C 的路线准备；PC → STM32 的连接方式仍取决于现有开发板接口。
- 用户先前提供的商品长图已明确说明可通过 UART／I²C 控制各路舵机，不能再将“是否支持控制、是否仅调试口”列为待询事项。命令格式等细节应先查该控制板的专用教程与协议。
- PC → USB 转 TTL → 控制板 UART 可作为简化备选，是否适用以协议和电平确认为前提。
- USB 摄像头仍单独连接 PC，图像不经过舵机控制板。

## 已有图片明确提供的信息

2026-10-29 重新放大核对用户原图 `2360f9134b8c1debf59656c10a038310.jpg`，本机阅图切片保存在忽略目录 tmp/hardware-review/。

- 支持串口与 I²C 发送命令，16 路舵机可单独控制；串口可接选配蓝牙模块控制舵机。
- 厂商 STM32 核心板示例：控制接口 VCC → 3.3V、SCL → PB6、SDA → PB7、GND → GND。此为厂家示例，不代表用户现有 STM32 的型号或固定引脚分配；也不是让 3.3V 给舵机动力供电。
- 控制板动力输入范围标称 5–8.4V，舵机动力电源取自输入，具体电压以所接舵机额定电压为准。
- 页面已列出 7.4V 电池供电与 5V 电源模块供电的示意，分别对应不同额定电压的舵机。
- S1–S8 和 S9–S16 分组过流保护，图片标称每组超过 2A 保护。

## 新的供电候选

用户确认原电池电压超过随货舵机允许范围，正在考虑多电源模块 V3.1（商品图标称 LM2596-3.3V／5V／ADJ）与固定输出 12V、1A 直流电源适配器，尚未记为已购或已验证。

候选连接为 12V 适配器 → 降压模块的 5V 输出 → 控制板动力输入 → 舵机。图片仅给出模块输入 6–25V、3.3V／5V／可调输出，没有给出各路持续电流及散热条件。12W 输入按假设 85% 效率估算对应约 5V、2.04A，这是功率估算，不是模块实测能力或两轴启动验收。两只舵机的启动／堵转电流及供电瞬态仍未测量。

## 到货后顺序

1. 拍摄铭牌与接线，记录驱动板版本、舵机型号、电池和充电器规格。
2. 分别核对控制板输入、逻辑电源、舵机电源轨以及信号电平。将实际套组说明与舵机额定电压统一确认；不凭控制板稳压电路推断舵机电源已经降压。
3. 先用 PC 单独预览相机，记录设备名、格式、实际分辨率和 FPS，不连接闭环运动。
4. 云台固定到底板；整理线缆，保留俯仰和水平运动的松弛量。
5. 手动逐轴小范围测试，记录中位、正负方向、可用范围、限速与碰撞边界。
6. 验证 STM32 独立通信超时后保持位置，再进行水平单轴闭环。
