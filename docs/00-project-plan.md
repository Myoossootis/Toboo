## 采购前的优先顺序

1. 运行 `scripts/verify.ps1`，读一份 telemetry.csv，理解偏差、状态和命令角度。
2. 生成并打印 ID 7 标记；在打印件上测量黑色方块边长，贴在平整硬板上。
3. 确认已有 STM32 的完整型号、电脑通信方式和可用 I²C 引脚，补充 hardware/ 的记录。
4. 通过 `--config` 复制不同参数文件做模拟比较；仅讨论控制趋势，不据此宣称实机精度。
5. 若有普通电脑摄像头，可先用纸质标记测试 PC 视觉链路，但结果注明所用设备，不能替代所购摄像头的验收。
