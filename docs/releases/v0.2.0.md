# toboo v0.2.0

toboo 桌面陪伴原型的新版本，将 AI 对话、设备管理和视觉功能集中到同一桌面界面，并整理了项目入口、源码结构和公开文档。

## 使用方式

下载 **`toboo-0.2.0-win-x64-portable.zip`**，完整解压后双击 **`toboo.exe`**。自带 .NET 运行时，无需安装 SDK。源码用户可双击根目录 `start-toboo.cmd`。

## 主要变化

- 陪伴、设备和设置三页界面，保留高级视觉与硬件调试工作台。
- 在 toboo 内使用 DeepSeek Harness 模型服务：流式回复、停止、模型与风格选择、历史会话，以及独立聊天桥的重试去重与持久化处理。
- 本地七类面部表情线索分析、质量拒判、时间确认和过期清除；不确定时显示 Unknown。
- 独立 UNO 传感器遥测及合成故障场景回放。
- 源码整理为 Desktop、Cli、Core、Vision、Runtime 五个项目，共用代码统一编译。
- 更新公开 README、启动指南、架构和开发说明，移除当前源码树中的本地实验与个人资料。
- 便携包包含模型、原生运行库、第三方声明以及 Harness 桥接插件和安装脚本。

## 配置与限制

AI 对话需要另行安装并配置 DeepSeek Harness。桥接插件安装步骤见压缩包内的 `docs/harness.md`；首次安装后需从托盘完全退出并重启 Harness。

语音输入、语音输出和 LCD 发送仍待接入。便携版的实际舵机操作需要源码环境中的 Python 串口工具。旧设置继续使用原有本地目录，无需重新标定。

面部表情是可见线索，不能判断真实心理情绪。发布验证使用合成视觉、公开样本和专用测试会话，未据此宣称真实硬件性能或识别准确率。
