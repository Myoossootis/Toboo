# toboo v0.3.1

本版本改善云台准备流程，解决缺少相机角度模型时难以继续跟随的问题。

- 云台卡片提供「使用视场角估算并保存」。一键创建水平 60°、垂直 45° 的近似相机模型，优先采用当前摄像头预览尺寸，否则采用采集规格（默认 640×480）。界面明确说明模型未经实测标定。
- 复用已保存的舵机中心、工作边界及方向确认。快速配置不会确认供电、解锁执行器或发送运动指令。
- 快速准备的每一步显示缺项及下一步操作，避免只看到灰色按钮。
- 空闲时点击实物跟随会自动选择摄像头人脸模式。正在播放录像或运行其他实验时，提示先停止当前实验。
- 对固件不支持工作范围、缺少角度请求参考、视觉标定占用等情况给出对应提示。

## 更新方法

已有完整 v0.3.0 时，下载 `toboo-0.3.1-update-from-0.3.0-win-x64.zip`，关闭 toboo，将包内所有文件解压到原 `toboo.exe` 所在目录并替换同名文件。保留原有子目录，随后双击 `toboo.exe`。包内 `verify-update.ps1` 可检查覆盖后的程序文件。

新电脑或其他旧版本请下载完整的 `toboo-0.3.1-win-x64-portable.zip`。增量包不能独立运行。本次更新无需重刷固件。

## 启用跟随

选择 USB 摄像头，连接 ESP32 云台并确认外部 5V。若提示缺少相机模型，点击快速配置。已有方向与边界确认会继续使用，缺少请求参考时显式点击「回到中心」，再点击开启实物跟随。

若是新电脑，原机器人的配置须按 [便携版使用方法](../portable.md) 迁移。相机参数估算不能替代舵机安装后必要的边界和方向检查。

验证覆盖离线控制测试、界面准备流程、增量覆盖后的文件哈希及便携程序原生依赖与合成画面检查。实物跟随效果需在对应硬件上验证。
