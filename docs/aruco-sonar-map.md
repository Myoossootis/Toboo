# 手持二维建图与避障

在 toboo 的「设备 → 二维建图与避障」打开工作台。点「合成演示」可先看同一个纸箱从不同位置被测到时的地图效果。实物模式使用固定的 ArUco 7 作为地图原点，用 USB 摄像头记录手持移动轨迹，用 Uno 超声波标记障碍回波。

## Uno 与超声波共板接线

适用于 Labkit 的 5V 四针超声波模块。断开 Uno USB 后按模块丝印接线。LCD 和超声波可以通过面包板共用供电和地。手持测试只需 USB 摄像头和 Uno，舵机电源保持断开。

| 超声波 | Uno R3 | LCD1602 | Uno R3 |
| --- | --- | --- | --- |
| VCC | 5V | VCC | 5V |
| GND | GND | GND | GND |
| TRIG | D7 | SDA | A4 |
| ECHO | D8 | SCL | A5 |

使用 [LCD 构建环境](lcd.md#构建和上传)构建合并固件。上传前先断开 toboo 的表情屏连接，并把命令里的 COM7 换成设备管理器中显示的 Uno 串口。

```powershell
./scripts/build-uno-lcd.ps1 -EnableUltrasonic
./tmp/esp32-tools/cli/arduino-cli.exe upload --config-file tmp/esp32-tools/arduino-cli.yaml --fqbn arduino:avr:uno --port COM7 --input-file artifacts/uno-lcd-distance/uno_lcd.ino.hex --verify
```

上传后在「设备 → 表情屏幕」选择这个 Uno 的 COM 口并连接。工作台会显示「Uno 表情屏与超声波已连接」。两项功能复用同一个串口连接。

## 标定与手持测试

1. 在设备页选中 USB 摄像头。若视觉感知正在运行，先停止，再打开「二维建图与避障」。
2. 点「保存棋盘格和标记」。将两张图等比例打印，保留白边。把棋盘格贴在平整硬板上。在工作台开启摄像头，将完整棋盘格放入画面，从中心、边角、不同距离和倾斜角度采集 12 张。标定结果会为当前相机和分辨率保存在本机。
3. 将 7 号标记正向贴在竖直墙面上，测试途中保持位置固定。用尺量黑色方框从外边到外边的边长，单位为毫米。停止采集后填入「标记黑边」，然后重新开始。100 mm 是初始值，填写实际印刷尺寸。
4. 将探头和摄像头固定在同一支架上，朝向一致，移动时尽量保持水平。镜头中心到两只换能器中点的偏移按右、下、前三个方向填写，反方向填负值。朝标记缓慢移动，并把纸箱放在探头正前方。观察轨迹与橙色回波区域，随后慢慢接近纸箱，核对是否在默认 350 mm 阈值内出现「停止建议」。

地图是以标记为原点的俯视观测图。橙色弧形格表示该段距离内可能有回波来源，格边长为 10 cm，空白区域为未知。丢失标记会暂停新轨迹和回波入图，新鲜的近距离回波仍会提示停止。无回波或测距过期时显示「信息不足」。当前范围为单标记可见区域，提示覆盖探头前方的波束，移动由手持操作者决定。
