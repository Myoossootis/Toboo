# toboo v0.3.2

本版本修正表情模型的人脸对齐实现，增加可检查的七类推理诊断，同时包含 v0.3.1 的相机快速配置和跟随准备改进。

- 五点对齐改为与固定版本 OpenCV Zoo 一致的模板拟合后求逆方式，修正关键点有残差时的裁剪偏差。模型权重及七类顺序保持一致。
- 设备页显示「本次模型推测」，详情页分别显示本次模型分数和平滑分数，以及分数、首二类差距和类别稳定性方面的拒判原因。
- 稳定表情继续要求最高分至少 0.60、首二类差距至少 0.15、连续确认至少 0.35 秒。本次推测仅供诊断，不作为稳定表情发送到 LCD 或聊天。失效时清除。
- 云台卡片保留「使用视场角估算并保存」，复用已保存的工作边界、中心和方向确认。

## 覆盖更新

关闭 toboo，将对应增量包内全部文件解压到原 `toboo.exe` 所在目录，合并子目录并替换同名文件，再运行 `toboo.exe`。

- 从 v0.3.0 更新：`toboo-0.3.2-update-from-0.3.0-win-x64.zip`，一次包含快速配置和表情改进。
- 从 v0.3.1 更新：`toboo-0.3.2-update-from-0.3.1-win-x64.zip`。
- 新安装或其他旧版本：`toboo-0.3.2-win-x64-portable.zip`。

已通过 v0.3.0 → v0.3.1 增量升级的安装也可使用 v0.3.1 对应包。增量包不能独立运行，更新无需重刷固件。本地标定与设备设置仍保存在原目录。

## 验证边界

对齐使用固定官方实现产生的数值样例做回归；七类诊断与丢脸清除使用合成分数测试，公开样图用于离线输入对照。覆盖更新检查目标文件哈希、便携依赖和合成画面启动。

上述检查不构成个人场景的七类准确率评测。实际表情识别效果需要在对应摄像头、光照及用户表情上验证。
