# 实验与数据规范

每次实验用独立目录：`artifacts/日期_实验编号_条件/`。原始录像放 data/raw/，统计结果放 data/processed/；大型文件不入 Git，README 或报告记录文件位置与校验值即可。

## 必须记录的条件

场景类别（synthetic／recorded／physical）、相机型号、图像尺寸、实际采集频率、标记 ID 和黑色方块尺寸、距离、光照、曝光设置、代码提交号、配置文件及操作步骤。运行的 `run.json` 保存配置快照，但人工实验条件仍需补齐。

## CSV 字段

| 字段 | 含义 |
|---|---|
| frame / time_s / capture_time_s | 图像编号、控制时刻、采集或文件名义时刻 |
| detected | 本帧是否找到唯一目标 ID |
| width / height / u_px / v_px | 实际图像尺寸和简单图像中心；无效时中心留空 |
| error_x / error_y | 归一化偏差；无效／旧帧保持时留空 |
| pan_command_deg / tilt_command_deg | 位置命令，不能用作实际轴角 |
| state | 控制器状态 |
| algorithm_ms | 本机检测与控制运算耗时，不等于曝光到运动的端到端延迟 |

## 统计规则

- 检测率分母为整个时段全部被处理的帧。实时模式会丢弃未处理旧帧，因此处理帧检测率不等于相机全部采集帧检测率；实物试验另记录采集／处理帧数。
- 居中成功率：检测有效且 abs(ex)≤0.10、abs(ey)≤0.10 的处理帧数 / 全部处理帧数。
- 缺失帧不能填零偏差。有效帧误差与缺失率同时报告。
- 静态对准明确稳态窗口；动态试验记录路径和运动范围，每种条件至少 3 次。
- 对照死区时保持路径、增益、限速、照明等条件相同。
- 程序墙钟执行速度不等于模拟的 30fps 时间轴。合成测试用于检查正确性，不报告为实际跟踪速度。

## 标定

使用平整棋盘格或 ChArUco，固定镜头和图像模式，采集不同位置及角度。保留独立验证图像；训练集重投影误差不能单独代表全视野精度。标定结果放 calibration/local/，不要提前制造一份虚假的内参 JSON。
