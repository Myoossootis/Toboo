# toboo v0.3.3 候选版

此版本用于验证表情显示和 ICS43432 语音输入改进，尚未发布为正式 v0.3.3。真实模块录音和云端识别效果确认后，再决定正式发布。

## 表情

高置信结果沿用最高分 0.60、首二类差 0.15、连续确认 0.35 秒的规则。新增较弱线索通道：原始与平滑结果均达到最高分 0.40、首二类差 0.08，最高类别一致并持续至少 0.80 秒时，界面显示「表情倾向」。类别频繁变化、低差距、丢脸和过期仍撤销结果。

低置信倾向不作为已确认情绪附带到聊天，也不冒充稳定的 LCD 表情线索。此调整不能让模型本来没有排在首位的类别强行胜出，个人场景的准确率仍需实测。

## ICS43432 → DeepSeek ASR

1. 在「设备 → 语音」选择 ICS43432 与对应 ESP32 串口。
2. 展开「模块识别与纠错」，选择「DeepSeek ASR · 云端」。
3. 输入自己的 DeepSeek API Key，保存语音设置。密钥在本机 Windows 账户下加密保存，聊天继续使用原 Harness。
4. 保持「先核对文字（暂停自动语音命令）」开启。按住陪伴页语音按钮说话，松开后查看原文和校正文字，再确认发送。核对模式下不自动执行语音跟随命令。

官方 ASR 接口为 `POST https://api.deepseek.com/v1/tools/asr`，本程序发送 16kHz、16 位、单声道 WAV。服务会收到本次录音并计费；可随时切回本地识别。音频不会默认保存到磁盘，也不会在云端失败后自动切到其他服务或重发。

可选纠错使用 `deepseek-flash` 校正明显错字和项目术语。数字、否定词变化或改动过大的建议会被拒绝，识别原文始终保留。模型纠错不能保证理解正确，修改过的文字仍需人工核对。经过纠错的文字不会自动触发硬件命令。

本地 Whisper 保留，增加中文项目术语提示和三路束搜索。语音详情显示原始录音音量、时长及过载提示，用于区分采音和识别问题。

## 验证与限制

协议、WAV 格式、错误处理、取消、密钥加密和纠错保护使用模拟请求与合成录音验证。云端识别的真实中文准确率，需要在软件内配置 API Key 后，用实际 ICS43432 录音确认。候选阶段不操作舵机，也不将未解决的笔记本重启问题视为已修复。
