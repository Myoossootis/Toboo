# 桌面实验台

启动：`dotnet run --project src/PanTiltTracker.Desktop`。Windows x64 / .NET 8，使用 Avalonia 11.3.22，无需 Visual Studio。原命令行程序仍可独立运行。

## 基本操作

1. 图像来源默认“合成场景”。设置目标 ID、两轴增益、转速上限、死区与方向。
2. 点击“开始实验”，预览、检测状态、偏差、命令角度和误差曲线实时更新。运行中锁定设置；停止后修改，下一次开始生效。
3. “模拟遮挡”隐藏合成目标：立刻保持命令，持续缺失后显示丢失；关闭遮挡后重新检测并限速恢复。
4. 点击“停止”。日志自动写入 artifacts/desktop/ 的独立运行目录；“导出 CSV”可另存副本。
5. “生成标记”保存带白边的 PNG，默认字典 DICT_4X4_50 / ID 7。打印后测量黑色方块的实际尺寸。

图片只处理一帧后完成；视频按标称帧率回放。切换来源时清空上一次画面与指标，避免把旧结果误认为新来源数据。已有日志仍保留在原目录。USB 模式请求 640×480 / 30fps，实际模式与驱动行为待验证。

## 指标与边界

- 偏差以画面宽／高归一化；目标丢失时显示“—”，曲线断开，不填零。
- 有效检测率以本次全部处理帧为分母；不代表全部相机采集帧的检测率。
- 处理更新按实际墙钟统计，运算耗时为检测与控制耗时，都不等于端到端运动延迟。
- 角度是命令，当前无串口发送。没有真实舵机位置反馈。
- 合成相机理想跟随命令，没有模拟真实镜头、USB 延迟、机械回差或扭矩。
- 原始截图、标定及日志不上传；本项目不连接外部服务器。

## 验证

新增 6 项 Avalonia 无界面测试：1280×860 与 980×700 布局，启动／遮挡／恢复／停止／导出，缺失输入提示，实际单图检测及切换来源清空，运行中关闭窗口的任务清理。测试用 Skia 渲染，预览图位于 artifacts/desktop-preview/。

原生窗口能够启动；本次 computer-use 的窗口捕获两次超时，因此不将原生窗口截图或原生鼠标操作记为已验证。无界面测试不替代摄像头与系统文件对话框的实物验收。
