# toboo v0.3.4

本版本在 v0.3.3 基础上补强跟随目标的新鲜度检查与工作区边界保护，新增完整的[边界检查与保护说明](../safety.md)。

## 跟随保护

- **合并计算帧年龄**：同时计入主机报告的画面年龄与传输工具内的排队时间。例如画面已过去 120ms、排队再耗时 100ms，总年龄超过 200ms，发送保持请求，避免继续追逐过期目标。后续新鲜目标可以继续正常跟随。
- **传输启动前再次检查工作区**：校验边界数组数量、S1/S2 范围、上下限顺序及轴选择；无效参数在启动串口工具之前被拒绝。
- **冻结本轮边界**：复制工作区为会话独立快照，防止调用方在异步启动期间改写数组、扩大本轮范围。小范围试跟随仍只能缩小工作区。
- **取消优先**：已取消的启动请求不再启动传输进程。

本版本没有修改用户保存的中心、工作边界、方向和相机标定，没有放宽固件角度范围。无需重新烧录 Uno 或 ESP32。默认仍为预览/待机，不因更新自动恢复运动。

## 保护说明

新增资料按模块列出舵机限幅与限速、启动门控、丢脸和过期数据处理、通信超时和重放保护、超声波和建图、表情与语音、模型与发布校验，提供对应代码和测试索引。

明确区分请求角度与实测轴角、通信停发与动力断电、超声波停止建议与实际制动。当前没有编码器、堵转电流或独立断电急停反馈；本版本不将这些能力描述为已实现。

## 安装和更新

- 已有 v0.3.3：下载 `toboo-0.3.4-update-from-0.3.3-win-x64.zip`，关闭 toboo，把包内全部文件解压覆盖到原 `toboo.exe` 所在目录，合并子目录并替换同名文件。可运行 `verify-update.ps1` 核验。
- 新安装、其他旧版本或候选版：下载 `toboo-0.3.4-win-x64-portable.zip`，完整解压到新文件夹后运行 `toboo.exe`。
- 设备和语音配置保持原位置。完整步骤见[便携版说明](../portable.md)。

## 验证范围

298 项 .NET 测试通过，4 项外部素材测试跳过；12 项桥接测试、45 项 Python 无串口测试、6 个 C++ 主机逻辑测试程序通过。新增回归覆盖总帧年龄、保持后恢复、非法边界、边界快照与提前取消。

便携包及覆盖更新另检查文件哈希、独立运行时、原生依赖和合成画面启动。测试没有打开实物串口、烧录固件或驱动舵机，不构成真实机械余量、堵转或制动验证。此前真实语音准确率、个人表情效果及笔记本重启原因的验证限制继续适用。
