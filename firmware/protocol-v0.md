# PC → STM32 项目协议草案 v0

状态：设计草案，未在 PC 或 MCU 实现；不属于亚博驱动板协议。

为便于串口终端调试，初步采用 ASCII 行协议，以 LF 结束。连接速率及 UART／USB CDC 方式待开发板确认。角度数值采用十分之一度整数，避免区域小数点差异。

```text
SET,42,900,850\n
ACK,42,900,850\n
ERR,42,RANGE\n
```

含义：SET 指定序号 42 的水平 90.0°、俯仰 85.0°命令；ACK 只确认接受的命令，不代表实际轴角到位。MCU 应限制行长度、核对字段、拒绝超范围／畸形命令，并独立处理通信超时。

拟定连续 0.5 秒未收到有效命令时保持最后位置；启动时不要因任意残留字节触发运动。超时、限位及错误响应必须先在串口模拟／LED 状态上验证，再接舵机。

项目首版尚未加校验和；到实际链路阶段根据传输方式决定是否补充。在协议冻结和测试前，不启用实际运动输出。
