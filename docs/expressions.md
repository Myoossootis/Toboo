# 本地表情线索分析

使用 YuNet 五点人脸关键点对齐到 112×112，再以 OpenCV Zoo Progressive Teacher / MobileFaceNet ONNX 推理。v0.3.2 修正了对齐方向：按官方代码先将模板拟合到观测关键点，再求逆变换；五点不能完美匹配时，旧版直接拟合到模板的结果会不同。七类标签依次为 angry、disgust、fearful、happy、neutral、sad、surprised。模型版本、哈希和许可见 `models/expression/` 与第三方声明。

视频沿用既有人脸空间锁定；不会因另一张脸变大就切换对象。人脸太小、贴边、关键点/姿态不合格、模糊或光照异常时拒判。质量阈值是开发初值，需要针对场景评价。

最多约 5Hz 尝试分析；分数先经稳定 softmax，再进行时间常数 0.25 秒的指数平滑。最新结果和滤波结果均需最高分 ≥0.60、首二类分差 ≥0.15、类别一致，并持续 0.35 秒才显示稳定标签。分数未经概率校准，不能当作识别准确率。

v0.3.3 候选版新增低置信「表情倾向」显示：原始和平滑结果都需最高分 ≥0.40、首二类差 ≥0.08、类别一致且连续至少 0.80 秒。静态单图不走此通道；类别跳变会重新计时。倾向仅用于界面参考，不作为稳定情绪提供给聊天或 LCD。稳定标签的高置信条件保持不变。

设备页的「本次模型推测」显示最近一次有效推理的最高类别与分数，主表情标签显示连续确认后的结果。详情页分别列出本次模型七类分数和平滑后的七类分数，并说明拒判发生在原始分数、类别差距还是平滑确认阶段。本次推测不会作为稳定表情驱动 LCD 或附带到 AI 对话。丢脸、质量拒判和结果过期时一并清除。

`expression.jsonl` 保留原有 `modelScores`（平滑后的分数），新增 `rawModelScores` 与 `alignment`，便于定位原始模型错误和后处理拒判。日志没有人脸图片。七类诊断测试使用合成分数验证类别均可显示，不代表已测得七类真实识别准确率。

丢脸、低分、无效/重复帧立即撤销旧标签；切换目标或样本间隔超过 0.5 秒重新确认。相机帧年龄超过 0.2 秒不分析，结果年龄超过 0.5 秒失效。静态图片结果明确标为未连续确认。

模型缺失或推理异常降级为 Unknown，不改变目标选择或运动许可。图像不通过该算法上传。网络分类属于可见表情线索，不能据此作心理或健康判断，也没有声称在实际用户场景中达到特定准确率。
