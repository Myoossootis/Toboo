# toboo v0.3.5

- 新增 5 秒演示启动动画、语音音量和连续对话。唤醒一次后，可以在每轮回复结束后直接说下一句。
- 连续语音可以在本地 Whisper 转写后使用 DeepSeek 校正文字。输入栏下方显示处理结果，设备页提供原文和校正结果。
- 常见语音指令直接在 toboo 内执行，包括关闭语音唤醒、结束语音对话、开启或停止摄像头跟随。实物跟随仍需要设备就绪。
- Windows x64 便携包顶层提供带 toboo 图标的 `toboo.exe`，运行库和模型移入 `app/`。包内自带 .NET、图像、语音和串口依赖。

首次使用或从旧版升级，请完整解压到新文件夹并双击 `toboo.exe`。AI 对话需要按[便携版说明](../portable.md)连接 Harness。
