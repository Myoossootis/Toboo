# toboo v0.2.1

将本地表情识别接入 UNO + I²C LCD1602，并补齐 Windows 便携版串口支持。

下载 `toboo-0.2.1-win-x64-portable.zip`，完整解压后双击 `toboo.exe`。在设备页填写已确认的 UNO 串口并连接表情屏，再开启摄像头视觉感知。UNO 需先烧录专用 LCD 固件，接线与构建步骤见包内 `docs/lcd.md`。

## 新增与修复

- 七类已确认表情显示 ASCII 颜文字和英文标签；无有效线索时显示 `(?) / No valid cue`。
- 停止相机、离开画面、关闭表情识别或结果过期时清除旧结果，固件还具备独立的 500ms 内过期处理。
- 一次只发送一条请求并等待确认，不排队重放旧表情；剩余有效期扣除样本年龄与主机调度延迟。
- 桌面程序内置 .NET 串口连接，LCD 功能无需 Python 或源码目录。端口错误、取消、超时和拔线均有明确状态。
- 包含专用 UNO 固件源码、固定工具链说明和第三方许可证；不自动烧录，也不触发云台运动。
- README 增加四线接线示意、引脚表和两张真实硬件照片。

现有 UNO 固件与实屏已完成表情变化及离开后恢复的联调确认。软件验证涵盖协议、失效清除、界面和解压运行；这些检查不代表心理情绪识别准确率或舵机性能测量。

语音输入和语音输出仍待接入。LCD 固件与 UNO 传感器固件二选一，同一个串口不能同时连接两种服务。实际舵机调试仍使用独立的源码 Python 环境。
