# toboo 项目阶段与验收

项目转为 **toboo · 桌面陪伴机器人**。现有的人脸跟随、双轴运动、边界和通信故障保护是基础，下一阶段扩展 Labkit 多传感器交互。详细选型和评分依据见 [多传感器方案](18-toboo-multisensor-plan.md)。

## 已有基础

- ESP32-S3 N16R8、独立 5V 舵机驱动、USB 摄像头、C# 桌面程序。
- S1 现役工作请求 30–175°；S2 已换蓝色 SG90，工作请求 50–150°，中心 (103°,100°)。这些是请求参考。
- 本地 YuNet 人脸锁定、双轴跟随、回位与矩形/交叉对角线检查。
- 超界保持及提示；串口异常停发但保留画面；默认打开无动作。
- 新 S1 到货前暂停响应速度优化，不改变当前控制增益与速度。

## 下一阶段

| 阶段 | 工作 | 验收证据 |
| --- | --- | --- |
| T1 产品整理 | toboo 更名；无人机识别独立归档；保留通用视觉与运动代码 | 构建/回归通过，主线无无人机入口 |
| T2 可靠采集 | 核对 MMA、TMD、超声波、PIR；独立 UNO USB 遥测 | 原始读数、设备 ID、新鲜度/异常标志、断连演示 |
| T3 融合行为 | 在场唤醒、近手互动、姿态保护、夜间模式 | 同一场景下单传感器与融合对照，事件延迟与误触发统计 |
| T4 扩展与性能 | 声音、DHT11；到货后新 S1 校准与响应优化 | 多速率日志、静态噪声与消融实验、保留旧基线 |
| T5 课程交付 | 提案、完整演示、10–15 页报告 | 可复现实验、局限、不确定性和未实现项清单 |

传感器融合当前为计划，不用演示占位值冒充实物数据。新增模块必须展示标定、时序、失效处理和可见行为；Core 继续不依赖图像、UI 或串口。
