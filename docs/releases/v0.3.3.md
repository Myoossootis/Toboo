# toboo v0.3.3

本版本改进持续弱表情线索的显示，为 ICS43432 增加 DeepSeek ASR 和可选文字纠错。包含 v0.3.2 的人脸对齐修正与相机快速配置。

## 表情线索

- 愤怒、厌恶、恐惧、开心、中性、悲伤、惊讶七类继续使用原模型。持续较弱的有效结果可显示「表情倾向」，减少只因未达到稳定阈值而长期没有提示的情况。
- 原始和平滑结果的最高分均至少 0.40、首二类差至少 0.08、最高类别相同且持续至少 0.80 秒，才显示倾向。静态单图、类别跳变、丢脸和过期结果不会直接放行。
- 稳定结果仍要求最高分至少 0.60、首二类差至少 0.15，并持续至少 0.35 秒。低置信倾向仅在界面显示，不作为已确认情绪附带到聊天或 LCD。
- 本次没有重新训练模型，不能保证每个人的愤怒或悲伤都能正确识别，也不用于判断真实心理情绪。

## ICS43432 语音输入

1. 在「设备 → 语音」选择 ICS43432 和 ESP32 串口。
2. 展开「模块识别与纠错」，选择「DeepSeek ASR · 云端」。
3. 在软件内输入自己的 API Key，点击保存语音设置。聊天继续使用现有 Harness。
4. 保持默认「先核对文字」开启。按住语音按钮说话，松开后检查原文和校正结果，再确认发送。

录音以 16kHz、16 位、单声道 WAV 上传到 [DeepSeek 官方 ASR](https://api-docs.deepseek.com/guides/asr/)，按服务计费。密钥使用当前 Windows 账户加密保存在本机，更换电脑需要重新配置。失败不会自动重发或切换服务。

可选纠错使用 `deepseek-flash` 校正明显错字和项目术语。原文始终保留；数字（含正负号）、否定词变化或改动过大的建议会被拒绝。纠错文字不会自动触发硬件命令，核对模式暂停自动语音命令。

本地 Whisper 仍可离线使用，增加中文术语提示与三路束搜索。语音详情显示录音时长、原始音量及过载提示。电脑系统麦克风继续使用 Windows 中文识别。

## 安装和升级

- v0.3.2：下载 `toboo-0.3.3-update-from-0.3.2-win-x64.zip`，关闭 toboo，把包内全部文件覆盖到原 `toboo.exe` 所在目录。可运行 `verify-update.ps1` 核验。
- 新安装、其他旧版本或候选版：下载 `toboo-0.3.3-win-x64-portable.zip`，完整解压到新文件夹，双击 `toboo.exe`。
- 本次无需重新烧录 Uno 或 ESP32，保留本机配置、标定与舵机方向。本机配置路径和迁移方法见 [便携版说明](../portable.md)。

## 验证范围

自动化验证覆盖表情时间确认、语音取消与错误处理、密钥加密、WAV 格式、模拟接口、纠错保护及合成中文录音。便携包和覆盖更新还检查目标文件哈希、独立运行时、原生依赖及合成画面。

本版本没有新增真实 ICS43432 → 云端服务的准确率评测；个人表情准确率也需实测。此前笔记本重启的原因仍未确认，本次不宣称修复该问题。本轮发布验证不驱动舵机。
