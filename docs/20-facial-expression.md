# toboo 本地表情线索识别

2026-11-09：已接入桌面图片、录像、USB 摄像头人脸模式。只做可见面部表情分类，不识别身份，不把结果当作心理情绪或健康判断。目前不融合语音/文本，不调用 DeepSeek，也不输出 LCD 或舵机动作。

## 算法链路

1. **人脸检测与选择**：复用现有 YuNet；同一次前向计算额外解码眼睛、鼻尖、嘴角五点。录像/摄像头沿用现有空间锁定，不因另一人的脸变大而转去分析另一人。图片选择最大人脸。
2. **质量检查**：人脸至少64×64像素，不贴图像边界；关键点有效、双眼间距与鼻尖位置满足粗略姿态条件。对侧脸/遮挡保守拒判，现有跟随仍可继续。
3. **五点对齐**：五点最小二乘非反射相似变换到112×112，不隐式镜像。使用与上游一致的五点模板。
4. **亮度和清晰度**：对齐图灰度均值需在25–235之间，Laplacian方差至少35；均为待实测标定的初值，不承诺涵盖所有遮挡、光照或姿态。
5. **网络推理**：RGB / NCHW，`(pixel-127.5)/127.5`。七类输出 logits 只做一次数值稳定 softmax。标签顺序 angry、disgust、fearful、happy、neutral、sad、surprised。
6. **时间平滑**：按采样时间进行指数平滑，时间常数0.25秒；最多每0.2秒尝试一次表情分析，约5Hz。画面与人脸检测仍按原会话更新。
7. **不确定性与连续确认**：最新输出和滤波结果都需最高分≥0.60、首二类分差≥0.15，且最高类别一致；同一候选持续0.35秒才显示标签。分数为未校准模型分数，不是“真实情绪概率”或识别准确率。
8. **立即撤销旧结果**：丢失已选人脸、无效关键点、质量不合格、重复帧、低分/冲突立即回到 Unknown；更换锁定目标或样本间隔>0.5秒，清空历史重新确认。输入相机帧年龄>0.2秒不分析，结果年龄>0.5秒失效。UI独立检查过期，避免相机停帧时旧笑脸一直显示。

单张图片可显示一次分类，但明确标为“单张图像，未连续确认”。录像使用名义帧序时间；相机使用既有单调时钟。没有用墙钟积分或补造观测。

## 软件入口与边界

```powershell
./scripts/start-toboo.ps1 -Expression
# 或正常启动，选择“人脸”，进入左侧“表情”页
```

默认启用“本地表情识别”，运行前可关闭。支持图片、录像与USB摄像头；选择“仅预览”即可使用，无需连接或使能舵机。“表情”页显示七类分数、拒判原因、颜文字和最近推理耗时；画面下方同步显示摘要。

表情推理在原有跟随请求/确认之后执行，不参与目标选择、角度、使能或运动许可。它与跟随使用同一处理线程，最多5Hz，可增加该帧处理耗时；并非独立实时控制保证。模型缺失、损坏或推理异常只让表情功能退回未知，不使能执行器，也不替代原有失帧/串口保护。

Core：纯数据、softmax、时间状态机；Vision：模型、原生图像缓冲与对齐；Desktop：可选分析会话、日志、显示和过期提示。没有新增串口协议、物理动作或舵机响应参数修改。

## 日志与实验

每个启用表情识别的会话新增 `expression-settings.json` 和 `expression.jsonl`，位于忽略的 `artifacts/desktop/` 会话目录。记录帧号、捕获时间、最近模型样本时间、模型分数、标签、拒判原因、推理耗时、质量指标和锁定epoch。原有视觉/控制CSV保持兼容。

本次验证包括：

- `scripts/verify.ps1` 完整回归：139项通过（Core/Vision 86项、Desktop 53项），0失败、0跳过；Release构建0警告、0错误。运行时设置公开样本路径，不接实物执行器。
- 原生模型载入、SHA256、输入未修改、五点对齐不镜像、坏模型降级。
- 常量BGR图与上游Python预处理的七类分数对照，容差0.0001，用于检查通道顺序与归一化；这不是表情准确率试验。
- 时间确认、丢脸、换目标、长间隔、重复/未来帧、低分/冲突、过期清空。
- 公开OpenCV样本制成24帧录像，20帧有人脸、4帧空白；实际运行9次表情推理，空白帧立即清空。该样本没有表情真值，微笑/中性分数接近时保留Unknown，未报告准确率。
- 1280×860和980×700的界面渲染；分数列表支持滚动，原有视觉/舵机测试继续运行。

公开样本录像首次实测平均表情分析耗时约7.0ms（包含对齐、质量检查和网络，**不含YuNet检测、串口和相机采集**）。该数值是本机单样本检查，不能推广成实际相机帧率、最坏延迟或定位精度。

完整检查：设置 `UAVTRACK_FACE_TEST_IMAGE` 为公开人脸样本后运行 `scripts/verify.ps1`。未设置样本时，公开样本录像集成检查明确跳过；原生合成输入、时间逻辑和UI检查仍运行。新采集的用户画面、标注和实验结果继续只放忽略目录。

下一步评价应包含不同人、正面/侧面、远近、光照、遮挡与表情转换；数据按参与者划分，分别报告七类混淆、拒判率、覆盖率和错误稳定标签。若研究真实主观情绪，需要用户自述和独立实验设计，不以表情模型输出充当真值。
