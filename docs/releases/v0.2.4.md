# toboo v0.2.4

新增本地中文语音对话、ICS43432 麦克风接入和七类表情角色动作，并补充执行器输出锁定。修复候选版本构造启动参数时提前连接串口的问题；参数检查与已取消的执行不再触碰硬件连接。

## 语音与表情

- 陪伴页按住说话、松开发送；Esc 取消识别。新回复可自动朗读，下一次说话可以打断朗读。
- 电脑麦克风使用 Windows 中文识别；ICS43432 通过 ESP32-S3 采集 16kHz 单声道音频，使用本地 Whisper base 转写，先经 Silero VAD 检测人声。
- 便携包包含固定哈希的语音模型、CPU 运行库和模型修复脚本，无需 Python 语音环境。模块识别要求支持 AVX2、FMA、F16C 的 x64 CPU，详细系统条件见 [麦克风说明](../microphone.md)。
- 同一 ESP32-S3 原生 USB 可承载采音和云台协议。音频使用会话、序号、长度上限与 CRC32；异常、取消或断流会丢弃本次识别。
- 桌面与 Uno LCD 增加愤怒、厌恶、恐惧、中性、悲伤、惊讶等类别动作，与开心共七类表情线索；并保留待机、注意、思考和回应状态。完整实体动作需更新本版 Uno 固件。

## 执行器兼容性

当前跟随算法要求角度定位型舵机。360°连续旋转型只能控制速度与方向，不能用角度请求确定机械中心或左右边界。外壳或 SG90 名称相同不表示控制方式相同。

本 Release 的 ESP32 预编译固件为**全执行器输出锁定版**，仅适用于 ESP32-S3 N16R8：保留麦克风、状态查询和 DISARM，拒绝执行器使能、回中心、微调及跟随，不发送舵机角度帧。它不能清除外部驱动板原先保持的 PWM，也不代替动力断电。

桌面会保留已发现的输出锁定；保存旧边界或更新程序不能解除锁定。锁定表示需要重新核对硬件与参考，不代表应用检测到了具体舵机型号。升级桌面不会自动烧录固件或使能运动。已验证的定位型装置可参考 [硬件接口](../hardware.md) 自行构建适用版本；机械适配仍需独立验证。

## 下载与升级

- `toboo-0.2.4-win-x64-portable.zip`：完整解压后运行 `toboo.exe`，保留所有运行库与模型目录。
- `toboo-0.2.4-uno-lcd.hex`：独立 Uno LCD 动画固件，按 [LCD 说明](../lcd.md) 烧录。
- `toboo-0.2.4-esp32s3-n16r8-ics43432-motion-locked.bin`：16MiB 合并镜像，写入偏移 `0x0`；会覆盖原闪存内容，不能用于其他容量或 PSRAM 配置。
- `toboo-0.2.4-firmware-source.zip`：本版固件、固定工具链配置、构建脚本和 Uno LCD 所用的 hd44780 源码及许可证。
- 对应 `.sha256` 和 `SHA256SUMS.txt` 用于下载完整性校验。

聊天继续通过独立的 DeepSeek Harness 1.0.2 桥插件连接，界面在 toboo 中。语音原始数据默认仅在内存中处理，只有显式调试参数才会保存录音；对话模型收到的是发送的文字。

## 验证边界

发布前检查公开文件范围、锁定路径、协议单元测试、.NET 回归、合成视觉和传感器回放、Uno 与 ESP32 构建、独立解压运行及合成中文语音链路。本轮发布验证不连接执行器、不试转，也不代表新舵机的机械限位、真实位置、语音准确率或人脸表情准确率已经完成测量。
