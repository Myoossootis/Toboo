# 项目阶段与验收

更新：2026-11-07。当前优先人脸对准路线，无人机实验暂缓。手动双轴回位与矩形扫动已跑通；人脸的锁定、滤波和角度请求框架已加入，实际视觉自动闭环尚待接入与验收。

## 已确定的主路线

选择用户照片最上方的 **ESP32-S3 N16R8 带天线座双 USB 开发板**，实机已读到 16MB Flash + 8MB PSRAM，原生 USB 为 COM6；中间疑似 ESP32-C3 小板、下方 Keyes UNO R3 暂作备用。YD 接口图与 V1.4 原理图已核对，实物 PCB 修订仍未确定，见 [主控选型决策](decisions/0002-esp32-s3-controller.md)。

PC（C# 视觉）→ USB/串口 → ESP32-S3 → 独立 UART → 16 路舵机板 → 两只 YBSG90。相机仍单独 USB 接 PC。ESP32 由 USB 供电，舵机板动力使用外置 5V、3A，两者共地、正电源不并联，通信 VCC 留空。

11 月 6 日原无输出台架验收见 [台架记录](15-esp32-bench-validation.md)。11 月 7 日完成电源测量、单轴/双轴动作及完整手动扫动。当前固件 v0.4.0 提供双轴 S 曲线、范围和独立超时保护。S2 在 68–72° 有卡滞报告，当前工作请求范围为 S1 30–175°、S2 35–65°，实际轴角仍无反馈，见 [硬件记录](16-single-servo-bringup.md)。人脸上层计算与限制见 [人脸对准框架](17-face-aiming.md)。

## 现在的执行顺序

1. 使用固定摄像头模式，测量视场或标定内参，人工确认两轴修正方向。
2. 将人脸请求框架与硬件流式接口衔接，手动回位/扫动与自动跟随互斥，丢脸或旧帧时取消未完成运动。
3. 先低速单轴再双轴，记录中心误差、超调、稳定时间和丢脸停止延迟。默认配置不提供镜头几何或安装方向，不自动输出。
4. 补做带载供电、卡滞范围与机械边界检查。命令角和状态确认均不代表实测轴角。
5. 行为变更运行 scripts/verify.ps1，并保留控制/超时测试。原 ArUco ID 7 和无人机实验代码供对照，不将其结果当作人脸实物验收。

## 暂不加入

本轮主控与上电阶段不加入 FPGA、三维姿态、卡尔曼预测、无线控制或自动搜索扫描。神经网络训练属于独立视觉改进计划，不作为裸板/手动单轴验证的前提。已有 Avalonia 实验台继续使用；复杂设备配置和标定界面留待后续。
